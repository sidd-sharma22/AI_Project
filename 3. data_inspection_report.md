## 2. In-Depth Analysis

### A. Missing Values (NaN / Null)
- **Parquet Splits (`dataset/*.parquet`):** Zero missing cells found across all 4.81 million rows.
- **Raw CSV Context (`REGULAR.csv.gz`, etc.):** In the original raw CICFlowMeter CSVs, missing values typically occur in rate calculation columns (e.g. `Flow Bytes/s` when `Flow Duration = 0`). The pre-packaged parquet datasets resolved these, and our `clean_features()` method in `src/data_loader.py` defensively replaces any NaNs with the column median/0.

### B. Infinite Values (`+inf` / `-inf`)
- **Parquet Splits:** Zero infinite cells found.
- **Defensive Preprocessing:** Our pipeline implements `USBIDSDataLoader.clean_features()`, which detects any infinite floating-point values and replaces them with the respective feature's maximum/minimum finite values.

### C. Duplicate Rows
- **TEST Split:** 0 duplicate rows.
- **VALIDATION Split:** 0 duplicate rows.
- **TRAIN Split:** Exactly 6 duplicate rows out of 3,369,070 flows (< 0.0002%). 
- In network flow statistics, identical flows can legitimately occur when identical SYN probe packets are sent at the same millisecond timestamp with identical header parameters.

### D. Zero-Variance (Constant) Features
Across all splits, exactly **6 columns** have zero variance (single constant value of 0):
1. `Fwd URG Flags`
2. `Bwd URG Flags`
3. `URG Flag Count`
4. `CWR Flag Count`
5. `ECE Flag Count`
6. `Subflow Bwd Packets`

**Cybersecurity Rationale:**  
In HTTP/TCP DDoS attack testbeds, the Urgent pointer (`URG`), Congestion Window Reduced (`CWR`), and Explicit Congestion Notification Echo (`ECE`) flags are virtually never utilized by modern HTTP web servers or flooding scripts like HULK.

### E. Class Distribution & Imbalance
Across the 4,813,066 total flows:
- **Benign Traffic:** 304,733 flows (~6.3% of dataset)
- **HULK Attacks:**
  - `Hulk-Reqtimeout`: 855,630 flows
  - `Hulk-NoDefense`: 851,130 flows
  - `Hulk-Security2`: 813,046 flows
  - `Hulk-Evasive`: 756,985 flows
- **TCPFlood Attacks:** ~900,000 flows
- **Slowloris & Slowhttptest:** ~30,000 flows

## 3. Preprocessing & Normalization Protocol
1. **Benign Isolation:** As specified in Section 4.2 of the paper, the Autoencoder is trained **strictly on Benign flows**.
2. **Min-Max Scaling:** Fitted exclusively on the Benign training set ($x_{\text{norm}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}}$) and used to transform evaluation scenarios without data leakage.
